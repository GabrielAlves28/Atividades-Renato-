# Atividade Prática Orientada - Programação Web I 

##  Objetivo
Aplicar conceitos fundamentais de PHP procedural, integração com formulários HTML, controle de sessão e uso de cookies.

##  Estrutura do Projeto
O projeto está organizado conforme os requisitos solicitados:

- atividade-1-classificacao/: Sistema de notas com estruturas condicionais e de repetição.
- atividade-2-formulario/: Simulador de cadastro usando o método POST e validação de campos.
- atividade-3-login/: Sistema de autenticação com proteção de páginas via $_SESSION.
- atividade-4-cookies/: Sistema que utiliza cookies para memorizar o nome do visitante por 7 dias.
- atividade-5-desafio-integrador/: Mini sistema completo integrando login, cadastro e exibição de dados.

##  Tecnologias Utilizadas
- PHP 
- HTML / CSS
- Git & GitHub
